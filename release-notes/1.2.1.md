Wave is now signed with Developer ID and notarized by Apple for simpler installation on macOS.

- The app and DMG include Apple's notarization tickets.
- Bundled Parakeet executables and libraries use the same Developer ID as Wave.
- The existing updater signing key is retained, so Wave 1.2.0 can install this release through Update and restart.

If you still use Wave 1.1.0, install this release manually once to move to the current updater key. Your projects and downloaded models stay in place.
